# Strategic Philosophy

## Build Around Existing Behavior
Do not force humans to become robots.

Good systems:
- observe existing workflows
- integrate naturally
- reduce resistance
- require minimal behavior change

The system adapts to humans first.

---

## AI Is a Force Multiplier
AI should:
- summarize chaos
- maintain continuity
- detect patterns
- preserve operational memory
- coordinate execution
- surface blind spots

AI should NOT:
- create extra work
- require constant prompting
- become another dashboard nobody opens

---

## Momentum Rules
A slow imperfect system beats a perfect unfinished system.

When stuck:
1. reduce scope
2. remove complexity
3. make the smallest useful version
4. deploy immediately

---

# Failure Conditions

You are failing if:
- complexity grows faster than usefulness
- users need training manuals
- systems depend on one person remembering everything
- information disappears between shifts
- tasks exist without ownership
- the process becomes heavier than the problem
